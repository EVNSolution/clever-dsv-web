# 고객 계정 발급 계약 초안

## 목적

고객 계정은 누구나 가입하는 공개 회원가입이 아니라, DSV 운영진이 등록된 고객사의 담당자를 초대하는 방식으로 발급한다. 운영진은 고객사와 계정의 연결 상태를 관리하고, 고객은 자신의 고객사 배송만 조회한다.

## 발급 흐름

1. 운영진이 관리 페이지에서 고객사와 담당자 이메일을 확인한다.
2. 운영진이 고객 계정 초대를 발송한다.
3. 서버는 원문 토큰을 저장하지 않고 토큰 해시, 만료 시각, 사용 시각을 저장한다.
4. 고객은 일회성 링크에서 본인 아이디와 비밀번호를 설정한다.
5. 활성화된 계정은 한 고객사에만 연결하며 다른 고객사의 주문과 배송 정보를 조회할 수 없다.
6. 초대 링크는 한 번 사용하거나 만료되면 다시 사용할 수 없다.

## 운영 규칙

- 고객 계정은 운영진이 고객사 상세에서 발급, 재초대, 비활성화한다.
- 공개 회원가입 API와 화면은 제공하지 않는다.
- 고객사 담당자가 바뀌면 기존 계정을 비활성화하고 새 담당자를 초대한다.
- 비밀번호 재설정도 이메일의 일회성 링크로 수행한다.
- 초대, 활성화, 비활성화, 비밀번호 재설정 이력을 감사 로그에 남긴다.
- 브라우저 세션 만료와 계정 비활성화는 별개의 상태로 취급한다.

## 후속 백엔드 작업

현재 고객 계정은 외부 발급자 식별자를 사용하므로, 자체 아이디와 비밀번호를 지원하려면 다음 계약을 별도로 확정해야 한다.

- 고객 계정 자격 증명 저장 방식
- 초대 토큰 모델과 만료 정책
- 비밀번호 강도, 변경, 잠금 정책
- 고객사와 고객 계정의 일대일 또는 일대다 정책
- 운영진의 재초대와 비활성화 API
- 고객 활성화와 비밀번호 재설정 화면

이 계약이 확정되기 전에는 프런트에서 예상 가입 API나 임시 인증 상태를 구현하지 않는다.
